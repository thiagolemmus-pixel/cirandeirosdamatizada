# Ciranda Flor Matizada — Catálogo de Cirandeiros

Catálogo digital para apresentar a história, os integrantes e os personagens da Ciranda Flor Matizada.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Executar localmente

Abra `index.html` no navegador. Não é necessário instalar dependências.

## Personalização

Edite `data/cirandeiros.js` para cadastrar os integrantes e substitua as imagens de demonstração pelas fotos autorizadas da ciranda.
